jQuery

Una librería de JavaScript creada para simplificar tareas comunes del desarrollo web.

¿Qué es jQuery?

jQuery es una librería de JavaScript que facilita tareas como seleccionar elementos HTML, manejar eventos, realizar animaciones y comunicarse con servidores.

¿Por qué nació?

jQuery surgió cuando los navegadores tenían diferencias en la forma de implementar algunas funciones de JavaScript. La librería permitió utilizar una sintaxis más sencilla y consistente.

Sintaxis básica

Una de las características más conocidas de jQuery es el uso del símbolo $. 

$("#producto").hide();

$(".boton").click(function() {
    alert("Producto seleccionado");
});

Efectos y animaciones

jQuery proporciona funciones sencillas para crear efectos visuales. 

$("#producto").fadeIn();

$("#menu").slideToggle();

JavaScript Vanilla vs jQuery

Acción JavaScript jQuery
Seleccionar elemento document.querySelector("#producto") $("#producto")
Evento click element.addEventListener("click", funcion) $("#boton").click(funcion)
Ocultar elemento element.style.display = "none" $("#elemento").hide()

Ventajas

  • Sintaxis sencilla.
  • Facilita la manipulación del DOM.
  • Incluye efectos y animaciones.
  • Fue muy útil para la compatibilidad entre navegadores.

Desventajas

  • Actualmente, JavaScript moderno ofrece muchas funciones similares.
  • Agregar una librería aumenta las dependencias del proyecto.
  • Para algunos proyectos modernos puede ser innecesario.
Ejemplo en SPORTIX:

jQuery puede utilizarse para mostrar u ocultar información de los productos, responder a clics y agregar animaciones a los elementos de la tienda.
