Hosting y Dominios

Cómo llevar un sitio web desde nuestro computador hasta Internet.

¿Qué es Web Hosting?

El Web Hosting es un servicio que permite almacenar los archivos de un sitio web en un servidor conectado a Internet. Gracias a este servicio, otras personas pueden visitar la página desde sus dispositivos.

Tipos de Hosting

Hosting compartido

Varios sitios web utilizan los recursos de un mismo servidor. Es una alternativa económica para proyectos pequeños.

VPS

Un servidor virtual privado ofrece recursos más controlados y mayor capacidad de configuración.

Hosting en la nube

Utiliza infraestructura distribuida para ofrecer escalabilidad y disponibilidad.

¿Qué es Vercel?

Vercel es una plataforma utilizada para desplegar aplicaciones y sitios web. Un proyecto puede conectarse a un repositorio de GitHub y desplegarse automáticamente.

En este proyecto:

El repositorio de SPORTIX puede conectarse a Vercel. Cada vez que se realice un cambio y se publique un commit, Vercel puede generar una nueva versión del sitio, si la integración está configurada correctamente.

¿Qué es un dominio?

Un dominio es el nombre que una persona utiliza para acceder a un sitio web. Permite encontrar una página sin tener que escribir directamente la dirección IP del servidor. 

www.sportix.com

TLD

TLD significa Top-Level Domain. Es la parte final de un dominio.

TLD Ejemplo Uso habitual
.com ejemplo.com Uso comercial y general
.org ejemplo.org Frecuente en organizaciones
.net ejemplo.net Relacionado originalmente con redes

¿Qué es un subdominio?

Un subdominio es una división dentro de un dominio principal. Puede utilizarse para organizar diferentes partes de un sitio web. 

blog.sportix.com

¿Qué es el DNS?

DNS significa Domain Name System. Es el sistema que permite relacionar los nombres de dominio con la información necesaria para encontrar los servidores correspondientes.

Cuando se modifica la configuración de un dominio, los cambios pueden tardar un tiempo en reflejarse en diferentes redes. A este proceso se le suele llamar propagación DNS.

Proceso de publicación

  1. Crear el sitio web en HTML, CSS y JavaScript.
  2. Crear un repositorio en GitHub.
  3. Subir los archivos y guardar los cambios mediante commits.
  4. Conectar el repositorio con Vercel.
  5. Configurar el despliegue y publicar el proyecto.
  6. Obtener la URL pública para compartir el sitio.
Importante:

Para publicar SPORTIX, verifica que los archivos HTML, el archivo style.css y la carpeta de imágenes estén incluidos en el repositorio. Comprueba también que los nombres y las rutas de los archivos coincidan exactamente.
