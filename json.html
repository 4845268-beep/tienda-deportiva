JSON

Un formato ligero para almacenar e intercambiar información.

¿Qué es JSON?

JSON significa JavaScript Object Notation. Es un formato de texto utilizado para representar información de manera estructurada. Es muy utilizado para intercambiar datos entre aplicaciones, servidores y APIs.

Estructura básica

JSON utiliza pares clave-valor. También puede contener arreglos y objetos. 

{
    "nombre": "SPORTIX PRO",
    "precio": 69.99,
    "disponible": true,
    "colores": [
        "verde",
        "negro",
        "naranja"
    ]
}

Objeto JavaScript vs cadena JSON

Objeto JavaScript JSON 
const producto = {
    nombre: "SPORTIX",
    precio: 69.99
};
 
{
    "nombre": "SPORTIX",
    "precio": 69.99
}

Objetos y arreglos

Un objeto contiene propiedades y valores. Un arreglo permite almacenar una colección de elementos. 

{
    "productos": [
        {
            "nombre": "SPORTIX PRO",
            "precio": 69.99
        },
        {
            "nombre": "SPORTIX RUN",
            "precio": 59.99
        }
    ]
}

JSON y las APIs

Las aplicaciones web pueden solicitar información a un servidor mediante una API. El servidor puede responder utilizando JSON. JavaScript puede recibir esos datos y utilizarlos para actualizar la página.

Ejemplo en una tienda:

Una tienda deportiva podría solicitar al servidor la lista de productos disponibles. El servidor respondería con datos JSON que JavaScript utilizaría para mostrar las tarjetas de productos.

Ventajas de JSON

  • Su estructura es sencilla de leer.
  • Ocupa relativamente poco espacio.
  • Permite intercambiar datos entre aplicaciones.
  • Es compatible con muchos lenguajes de programación.
