TECNOLOGÍA 01

JavaScript

El lenguaje que permite agregar comportamiento e interactividad a las páginas web.

¿Qué es JavaScript?

JavaScript es un lenguaje de programación utilizado principalmente para crear páginas web interactivas. Permite modificar elementos de una página, responder a las acciones del usuario y procesar información.

HTML + CSS + JavaScript

Tecnología Función
HTML Define la estructura y contenido de la página.
CSS Define colores, tamaños, posiciones y apariencia.
JavaScript Agrega comportamiento e interactividad.

Conceptos básicos

Variables

Las variables permiten almacenar información que puede utilizar el programa. 

let producto = "SPORTIX PRO";
let precio = 69.99;

console.log(producto);
console.log(precio);

Funciones

Una función es un bloque de código que puede ejecutarse cuando sea necesario. 

function saludar() {
    alert("¡Bienvenido a SPORTIX!");
}

saludar();

Eventos

Los eventos permiten ejecutar código cuando sucede algo, por ejemplo, cuando el usuario hace clic sobre un botón. 

const boton = document.querySelector("#comprar");

boton.addEventListener("click", function() {
    alert("Producto agregado");
});
Ejemplo práctico:

En SPORTIX utilizamos JavaScript para controlar el menú responsive, cambiar entre el modo claro y oscuro y mostrar un mensaje cuando el usuario pulsa el botón "Comprar ahora".
